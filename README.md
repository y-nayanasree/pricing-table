# Pricing Table

A responsive pricing table webpage created as part of my web development internship at Veda Technology.

## Features
- Three pricing plans: Basic, Pro, and Premium
- Highlighted popular plan
- Hover effects on pricing cards and buttons
- Responsive design for mobile and desktop screens
- Clean and modern user interface

## Technologies Used
- HTML5
- CSS3
